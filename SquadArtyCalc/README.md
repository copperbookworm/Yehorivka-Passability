## 它解决什么

网页版能算，但你得切出游戏、在地图上点目标。桌面版反过来：**你留在游戏里，按一个热键**——程序截取屏幕上 CURRENT GRID 那一小块，让 DeepSeek-V4.1-Flash 读出格号，再用同一套弹道内核算出密位与方位，结果永远置顶显示在一个半透明浮窗里。

## 功能

- **25 张官方地图** × **26 组武器/弹种**（部署 + 车载 + 常见模组），弹道与 [squadcalc](https://github.com/sh4rkman/SquadCalc) 46.1.0 逐条对齐（3,220 条解，最大误差 8.3e-14 度）。
- **四个热键**（都可改，支持 Ctrl/Shift/Alt 组合）：
  - `F1` 快速定位：截 1 次，坐标直接当目标
  - `F2` 准确定位：连截 3 次，取三点外心（2 点相同取中点，3 点相同按单点）
  - `F3` 清除坐标：清掉没算完的截图，上一次算好的目标保留
  - `F4` 浮窗显隐
- **浮窗**：半透明、文字不透明、可拖动，四行显示 阵地 / 目标 / 密位 / 方位，不抢焦点；空闲时 CPU 0.00%。
- **自动复制**：算完把目标格号写进剪贴板，游戏聊天里直接粘贴。
- **阵地高程**：在地图上点选即可，高程从 1024² 高程网格取（双线性插值）。
- **区域预设**：常用截图框可以保存、重命名、删除、一键套用。

## 用法（五步）

1. 双击 `Squad.exe`（首次会在同目录生成 `config.json` 与 `run.log`）。
2. 填 DeepSeek API Key → 保存。
3. 点「框选区域」，在游戏画面里框住 CURRENT GRID 那两行字（别把准星、队友标记框进去）。
4. 选地图与武器，在地图上点你的迫击炮阵地。
5. 切回游戏：按 `F1` 一次出结果，或按 `F2` 连截 3 次取外心。

## 已知限制

- 游戏请用「无边框窗口」，**独占全屏会盖住浮窗**。
- `F1` 常被 Snipaste 等截图工具占用；报错码 1409 = 热键被占用，换一个键或关掉占用程序。
- 只作估算：高程网格约 6 m 精度，弹道参数来自 squadcalc 的经验拟合（非 UE 物理），首发命中仍需校射。
- AI 可能把 `I` 读成 `L`（`I12-6-2` vs `L12-6-2`），程序会给出提醒，请自己核对一眼。
