# Squad 间瞄火力助手（桌面版）

把网页版《载具通行性地图》里的「间瞄火力计算 / 快速校准炮击」搬成独立桌面程序，再加一层
**AI 识图**：切回游戏按热键（默认 **F1 快速定位 / F2 准确定位 / F3 清除**，都可改成组合键），程序自动截取屏幕上的 CURRENT GRID 区域，认出目标网格坐标，
结合你在地图上点出的迫击炮阵地，直接算出**密位**与**方位角**，半透明浮窗盖在游戏上。

---

## 一、跑起来

```
双击  启动.bat
```

或命令行：

```
cd SquadArtyCalc
python main.py
```

依赖（已装好）：Python 3.14 + PySide6-Essentials 6.12 + Pillow + numpy。

## 二、第一次使用（三步设置）

1. **DeepSeek 密钥**：填进「DeepSeek 密钥」框 → 点「保存」。
   密钥存在同目录 `config.json`（明文，只在本机；不想留就删掉这个字段）。
   模型固定 `deepseek-flash`（DeepSeek-V4.1-Flash，支持读图）。
2. **框选识别区域**：点「框选区域」，屏幕变暗后**只框住游戏 HUD 里 CURRENT GRID 那两三行字**
   （框里别放血条、图标、地图，越干净越准）。框完会自动弹「预览截图」给你确认。
   框好的区域可以**存成预设**反复用，见下面「区域预设」。
3. **选地图 + 选武器**：地图 25 张官方图全在；武器 26 组（部署 3 + 车载 7 + 常见模组 16）。
4. **（可选）改热键**：面板上有四行，点一下右边的输入框，直接按下你想用的键即可——
   支持 **F1–F24、字母、数字**，也能加 **Ctrl / Shift / Alt**（例如 F5、Ctrl+Shift+D、Alt+Q）。

   | 功能 | 默认键 | 干什么 |
   |---|---|---|
   | **快速定位** | **F1** | 只截 **1 次**，读到的坐标直接当目标（快，适合移动目标/应急） |
   | **准确定位** | **F2** | 连截 **3 次**，取三点外心再算（准，抵消单次读数抖动） |
   | **清除坐标** | **F3** | 清掉**已截但还没算成目标**的坐标；上次算好的目标**保留不动** |
   | **浮窗显隐** | **F4** | 显示 / 隐藏半透明浮窗（原来占着 F2，现在挪到 F4） |

   按下即生效并写进 config.json，下次启动仍然是你设的键。
   - 改完会同步到界面上所有提示（副标题、两个识别按钮、玩法说明）。
   - 新键被别的程序占用时，下面提示行会变红「注册失败（错误码 1409…），换一个组合试试」，
     此时仍可点面板上的按钮照常工作。
   - 四个键**不能重复**：填了一个已经给别人用的键，会红字提示并自动回退。
   - 不建议用**单个字母**：全局热键会抢走这个键，游戏里打字、聊天都会误触发，建议加 Ctrl/Shift。

### 区域预设（保存 / 改名 / 删除 / 套用）

「识别区域」分组里有一行 **「区域预设」下拉 + 保存当前 / 重命名 / 删除**：

- **保存当前**：把现在这条框选区域存成一条预设，弹框输入名字（同名会覆盖）。默认名是
  「区域 1」「区域 2」…… 也可以自己起，比如「我的 HUD」「2K 准星区」。
- **重命名**：给下拉里选中的那条预设改名；重名会被拒绝并提示。
- **删除**：确认后删掉选中的那条；当前框选区域本身不动，只是去掉这条记录。
- **套用**：在下拉里选一条即生效，状态行写「· 预设「名字」」。
  手动重新框选后状态行变「· 未保存」，表示这条区域还没存进预设。

预设存在 `config.json` 的 `regions` 里（每项 = 名字 + 矩形），换分辨率或换显示器后
框一遍、用同名「保存当前」覆盖即可。

然后**在地图上点一下** = 设迫击炮阵地（会显示格号与高程，右键清除，滚轮缩放，按住左键拖动平移）。

## 三、游戏内怎么用

1. 开局先在游戏里看好自己架炮的格子，回到本程序在地图上点出来（只用点一次，之后一直有效）。
2. 切回游戏，把准星对着目标（HUD 上 CURRENT GRID 显示目标格），然后按：

   - **快速定位（默认 F1）**：只截 1 次，这个坐标直接当目标，浮窗立刻出密位/方位。
   - **准确定位（默认 F2）**：连截 3 次——**再挪一点点准星，按第 2、第 3 次**，
     程序把 3 个读数合成一个目标点（三点外心；两点相同取中点；三点相同按单点），
     抵消单次识别的读数误差（详见下面「三次截取取外心」）。

   截错了、或者 3 次没凑齐就不想继续了：按 **清除坐标（默认 F3）**，已截的作废，
   上次算好的目标原样保留。
4. 浮窗立刻给出**状态**和四个值：

   | 行 | 内容 |
   |----|------|
   | **状态**（最上面一行，带彩色圆点） | 🟡 **识别中 · 快速定位（1 次）** / **截第 n 个（n/3）· 正在识别**（点会跳动）→ 🟢 **计算完成 · 目标格号** / 🔴 **计算失败（原因）**；准确定位只截了 1~2 个时是灰点「①② 已记 X · 等第 3 个（3/3）」，没开始算时是「待命 · F1 快速 / F2 准确」 |
   | 阵地 | 你点的阵地格号 · 高程 |
   | 目标 | AI 从截图里认出的目标格号 · 高程；准确定位还没凑齐 3 个时显示「① K12-1-8（1/3）」这类进度 |
   | 密位 | 迫击炮/火炮该装的密位（mil） |
   | 方位 | 阵地→目标的方位角（°）——**固定在最下面一行** |
   | 底部小字 | 射角（武器自己的单位）、飞行时间、距离，或「不可达 / 小于最小射程」等提示 |

   看到 🟡 就是在等 AI 回话（通常 1～2 秒），看到 🟢 才是这次算成了。

5. **目标坐标会自动进剪贴板**：算成的那一刻，程序把最终的目标格号（例如 `K12-1-7`）复制到系统剪贴板，
   浮窗状态行末尾显示「· 已复制」，面板来源行末尾也追加「· 已复制」。切回游戏在小队频道
   `Ctrl+V` 就能直接把格号发出去，不用手抄。准确定位只截了 1~2 个的时候**不会**提前复制，
   以免把半成品盖掉你原本的剪贴板内容。

### 三次截取取外心（让目标坐标更准）

单人识图每次读数会有一两个子格的抖动，所以默认连截 **3 次**，合成一个目标点：

| 3 个读数的情况 | 算法 | 浮窗底部注明 |
|---|---|---|
| 三个坐标**互不相同** | 取三点构成的三角形的**外心** | 「· 三点外心」 |
| 有**两个**坐标相同 | 相同的两个算一个，与剩下的那个取**中点** | 「· 两点中点」 |
| 三个坐标**全相同** | 按**单点**（就是之前的方法） | 「· 三次一致」 |
| 三点几乎共线、外心算到很远 | 安全兜底：改用三点**重心**（外心离重心超过「60 m 与 6 倍最大边长」取大者才算数） | 「· 三点重心」 |

流程与提示：

| 动作 | 浮窗状态 | 目标行 |
|---|---|---|
| 第 1 次按**准确定位键** | 🟡 截第 1 个（1/3）· 正在识别 → ⚪ ① 已记 K12-1-8 · 等第 2 个（2/3） | `① K12-1-8（1/3）` |
| 第 2 次按**准确定位键** | 🟡 截第 2 个（2/3）· 正在识别 → ⚪ ①② 已记 K12-3-4 · 等第 3 个（3/3） | `② K12-3-4（2/3）`，底部列出已记的两个 |
| 第 3 次按**准确定位键** | 🟡 截第 3 个（3/3）· 正在识别 → 🟢 计算完成 · K13-4-3 | 最终格号 · 高程 |

- 3 次都要求准星对着**同一个目标**，只是轻微挪动一点，让读数来自不同采样点。
- 中间某次没读到坐标时（红字「第 2 个没读到 · 再截一次」）**已记的不会作废**，直接再按一次补上。
- 想反悔：按 **清除坐标键（默认 F3）** 或点面板上的 **「清除已截坐标」**，已记的几个作废；
  **上一次算好的目标会保留**（正在凑新目标时它只是暂时让位，清完就回来）。换地图会自动清空已截的。
- 手动在面板里写目标格（自测/校准用）走单点逻辑，不参与外心。

- 浮窗**半透明底 + 不透明文字**，可以鼠标拖动换位置（位置记进 config.json）；
- **F4**（默认）显示/隐藏浮窗；浮窗上右键也可隐藏或回到默认位置；
- 截图里没有坐标时，浮窗「目标」显示「无坐标」并给出提示，不会乱算；
- 面板上的 **「快速定位（F1）」「准确定位（F2）」** 两个按钮等同按对应热键，方便调试。
- 右侧面板底部的红色 **「退出程序」** 按钮：注销全部四个全局热键（还给系统）、关掉浮窗、保存配置，
  然后**完全退出**进程（任务管理器里不会残留）。每次识别之后如果不想要浮窗了，也可以直接用它收工。

## 四、演练（不用开游戏就能自测）

「演练（假 HUD，端到端自测）」会在你框好的识别区域里摆一块假 CURRENT GRID（随机格号），
这时按快速定位键（或准确定位键连按 3 次），程序截真屏 → 走真接口 → 出真结果。用来确认密钥、区域、识别链路都通，
再进游戏。演练窗关掉即恢复。

## 五、算法与数据来源

- 弹道与武器参数：**SquadCalc 46.1.0**（MIT-NC, sh4rkman）的 `squadFiringSolution` / `squadWeapons`，
  逐行搬到 `core.py`：抛体双解、飞行时间、散布椭圆、UB-32 的减速段、gravityScale、minElevation 射界、
  Moa 换算，全部按上游实现。
- 网格系统：与网页版同口径——300 m 主格 + 两级 3×3 子格（`C1-2-3` 这种写法），
  坐标换算直接用页面里那套 `kpTextAt` 算法，所以和网页版、和游戏 HUD 的写法对得上。
- 高程：25 张图各一份 1024×1024 高程网格（16 bit 归一化），双线性插值到米；
  和网页版用的同一份 heightmap、同一个公式 `(255+R-B)*zscale`。
- **一致性验证**：26 组武器 × 距离 100–4000 m（步长 100）× 高差 {-50, 0, +40}，
  与页面 JS 内核逐字段比对 3220 条解，**最大绝对误差 8.3e-14°**，一条不一致都没有。
- 识图：11 张真实 HUD 截图（`D:\mil-ai\IFC\grid-pic`）**11/11 全对，平均约 1.1 s**。
  模型是先出 reasoning 再出答案，`max_tokens` 给小了答案会是空的——所以代码里固定 400。

## 六、界面小说明

- 「地图」「武器」两个下拉列表是**深底白字**，展开后每项都可直接读（早期版本出现过黑底黑字）。
- 四个热键在「识别区域」分组下面排成四行（快速定位 / 准确定位 / 清除坐标 / 浮窗显隐）；
  **改键 = 点一下右边输入框，按下新键即可**（Esc 或点别处结束输入）。输入框里就是当前生效的键。
- 右侧面板内容较长，窗口比屏幕矮时会**自动出现滚动条**，底部「退出程序」始终固定可见。
- 窗口打开时会自动按屏幕可用区域缩放并居中，不会把底部按钮挤到任务栏下面。
- 浮窗四行数值从上到下固定是：**阵地 → 目标 → 密位 → 方位**（方位永远在最底下一行），
  等宽字体一眼扫读；状态行颜色：黄=算着呢、绿=成了、红=失败/打不到。
- 「识别区域」分组从上到下是：区域尺寸/坐标行 → 框选区域 / 预览截图 / 预览识别 → 演练 →
  **区域预设（下拉 + 保存当前 / 重命名 / 删除）** → 四个热键行 → 热键提示行。
- 面板固定 404 px，够放下四行热键和右侧按钮（早期 368 px 时右边「保存」「预览识别」会被裁掉一点）；
  下拉不会把面板撑宽，长条目由下拉自己截断。
- 算完会自动复制目标格号到剪贴板；写剪贴板走 Win32 API（Qt 连续写会偶发 `0x800401d0`），
  被别的程序占用时最多重试 0.5 秒，仍失败就只是不复制，不影响算出的数值。

## 七、已知限制 / 注意

- **AI 会把字母读错**：实测出现过把 `I12-6-2` 读成 `L12-6-2`。程序对以 I 开头的坐标会加一句提醒，但
  重要目标建议自己扫一眼格号。
- 识别区域里**不要有别的文字**（聊天框、击杀提示、载具名），否则容易读串。
- **独占全屏（Fullscreen）模式下浮窗可能被盖住**，请把游戏设成「无边框窗口（Borderless）」。
- 热键被别的程序占用时（控制台打印「注册失败，错误码 1409」，面板提示行变红），
  换一个键，或先用面板上的按钮顶着。F1/F2/F3/F4 各自独立，只影响被占的那个功能。
- 只支持**官方 25 张图**；模组地图没有高程数据，会提示「不在这张地图上」。
- 打不到的情况（超射程、射界外、弹丸寿命外、小于最小射程）：密位显示「—」，底部给原因，不会给假数。
  **坐标仍然会被复制**——格号本身是有效的，只是这一发打不到。
- 剪贴板里放的是**目标格号**（`K12-1-7` 这种），不含高程和密位；要发完整报点就照浮窗念。
- 高程是 1024 网格插值，1 格约 6 m；缓坡够用，断崖/桥下会有偏差。**只作估算**。

## 九、打包成单文件 exe（发给别人用）

现成产物：**`dist\Squad间瞄火力助手.exe`**（约 103 MB，单文件，双击就能用，不用装 Python）。

**发给别人时只需要发这一个 exe。** 首次运行会在 exe 同目录自动生成：

- `config.json`：密钥、识别区域与预设、四个热键、上次选的地图/武器、浮窗位置
- `run.log`：启动时间、热键注册结果、崩溃堆栈（无控制台时唯一的排查线索）

如果 exe 放在 `C:\Program Files` 这类不可写目录，这两个文件会自动落到
`%LOCALAPPDATA%\SquadArtyCalc\`。

**接收方第一次要做的事**：打开程序 → 填自己的 DeepSeek 密钥 → 保存 → 框选游戏里的
CURRENT GRID 区域 → 选地图与武器 → 地图上点阵地 → 回游戏按热键。

**两个必然遇到的坑（提前说清楚，省得以为是程序坏了）**

- Windows SmartScreen / 杀软会拦：程序没做代码签名，提示「未知发布者」时点「更多信息 → 仍要运行」。
  杀软报毒多半是 PyInstaller 单文件的自解压特征，把它加进信任即可。
- **F1 很可能已经被别的软件占了**（Snipaste 的截图键默认就是 F1，本机实测就是它）。
  这时面板热键行会变红提示「注册失败（错误码 1409）」，点右边输入框按个新键即可，
  比如 F5/F9 或 Ctrl+Shift+1；F2/F3/F4 各自独立，只影响被占的那一个。
- 同一个 exe 开第二个实例会弹「已经在运行」——两个实例会互抢全局热键，所以直接拦住。

**自己重新打包**（改了源码之后）：

```
cd SquadArtyCalc
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
  --name "Squad间瞄火力助手" --icon app.ico --version-file build\version_info.txt ^
  --add-data "data;data" ^
  --exclude-module tkinter --exclude-module PySide6.QtQml --exclude-module PySide6.QtQuick ^
  --exclude-module PySide6.QtNetwork --exclude-module PySide6.QtOpenGL --exclude-module PySide6.QtTest ^
  --distpath dist --workpath build\pyi --specpath build main.py
```

体积为什么这么大：PySide6 的 Qt 运行库约 60 MB + Python 运行时 + `data\` 里的 25 张底图与高程
（36 MB）。想瘦身只能牺牲 Qt（换 Tkinter 就得重写界面）或把地图数据拆成外挂包。

启动会比源码运行慢 1–3 秒：单文件模式每次启动都要先把内容解到 `%TEMP%\_MEIxxxx`。
自测：`Squad间瞄火力助手.exe --e2e`，会在 exe 同目录写出 `shot_main.png` / `shot_overlay.png`
并在 `run.log` 里打印解算结果（K11-4-3 → M10-1-7、63.4°、1346.2 mil 即正常）。

## 十、数字签名（自签名证书）

`dist\Squad间瞄火力助手.exe` 现在带 **Authenticode 签名**，证书是自签的：

| 项 | 值 |
|---|---|
| 主题 | `CN=Squad Arty Calc, O=mil-ai, C=CN` |
| 指纹 (SHA1) | `399F92D27CE8A9A413E724AD351A6C99CC12E446` |
| 算法 | RSA 3072 / SHA-256 |
| 有效期 | 2026-11-03 → 2029-11-03 |
| 时间戳 | DigiCert RFC3161（签名在证书过期后依然有效） |
| EKU | 代码签名 (1.3.6.1.5.5.7.3.3) |

证书与私钥备份在 `build\signing\`：

- `SquadArtyCalc-codesign.cer`：公钥证书，**发给别人时可选附带**，对方导入「受信任的根证书颁发机构」后
  签名才会显示成「已验证的发布者 · Squad Arty Calc」
- `SquadArtyCalc-codesign.pfx`：带私钥，用来以后重新签名，口令 `squadarty`（自签名证书，不必当机密看，
  但别把 pfx 发给别人，拿到它的人可以冒充这个签名）

**本机已经信任它**：`.cer` 导入到了 `Cert:\CurrentUser\Root` 与 `TrustedPublisher`，
所以现在 `Get-AuthenticodeSignature` 返回 `Valid / Signature verified.`。
不想要了可以撤销：

```
Remove-Item Cert:\CurrentUser\Root\399F92D27CE8A9A413E724AD351A6C99CC12E446
Remove-Item Cert:\CurrentUser\TrustedPublisher\399F92D27CE8A9A413E724AD351A6C99CC12E446
Remove-Item Cert:\CurrentUser\My\399F92D27CE8A9A413E724AD351A6C99CC12E446
```

**自签名能做什么、不能做什么**

- 能做：文件被改动过一眼能看出来（签名会失效）；Windows 文件属性里能看到签名者；
  对方信任这个 .cer 之后，UAC / SmartScreen 会显示「已验证的发布者 Squad Arty Calc」。
- 不能做：**消除 SmartScreen 的「未知发布者」**——那需要 OV/EV 代码签名证书（要花钱、要企业资质、
  还要攒下载信誉）。自签名只是"能证明这文件是我签的、没被篡改"。

**重新签名**（每次重新打包之后都要重签，签名会被新 exe 覆盖）：

```
$cert = Get-ChildItem Cert:\CurrentUser\My -CodeSigningCert |
        Where-Object { $_.Subject -eq "CN=Squad Arty Calc, O=mil-ai, C=CN" } | Select-Object -First 1
Set-AuthenticodeSignature -FilePath ".\dist\Squad间瞄火力助手.exe" -Certificate $cert `
  -TimestampServer "http://timestamp.digicert.com" -HashAlgorithm SHA256
Get-AuthenticodeSignature ".\dist\Squad间瞄火力助手.exe" | Format-List Status,StatusMessage
```

没装 Windows SDK 也能签（上面这条 `Set-AuthenticodeSignature` 是系统自带的）；
装了 SDK 也可以用 `signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a <exe>`。
