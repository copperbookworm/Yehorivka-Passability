# 地图区域标注

每张图的标注放在这里：

    annotations/<slug>/
      water.png        海洋 / 深水河，255 = 不可通行
      bridge.png       桥面，255 = 桥
      boundary.png     地图边界内侧，255 = 有效地图（没有文件 = 整张图有效）
      clear_road.png   手动通畅道路（树冠/桥下遮挡），255 = 可通行
      obstacle.png     手动不可通行障碍（护栏/围栏/石堆），255 = 不可通行
      boat.png         水面舰艇专用可通行航道，255 = 舰艇可走
      meta.json

由 `dist/map-water-bridge-annotator.exe` 或 `start-map-annotator.bat` 生成。

优先级（App 内，按当前载具类别）：

1. 地图边界外 → 不可通行
2. 手动障碍物 → 不可通行
3. 桥面 → 可通行
4. 手动通畅道路 → 可通行（陆地载具仍不能走水）
5. 海洋/深水河 → 陆地载具不可通行；两栖可通行；舰艇只在水域内
6. 其余按树冠/建筑/围墙/坡度判定

**水面舰艇航道是独立层**：只在 App 的“水面舰艇”类别下生效，地面载具忽略。
有 boat.png 时取 **水域 ∩ 航道**；没有 boat.png 时舰艇直接使用水域，不会全图不可走。

标注建议：

- **水域**：沿海岸线/河岸画闭合多边形，或笔刷 8–20 沿岸扫。
- **桥梁**：切桥梁层，笔刷 1–3 沿桥面画窄条，桥头各多盖 1–2 格。
- **地图边界内**：画一个把可玩区域包住的多边形；不画则默认整张地图都有效。
- **通畅道路**：切此层，沿被树冠/桥下遮挡但实际可走的道路画窄条。
- **不可通行障碍**：切此层，笔刷 2–5 沿护栏/围栏/石堆画。
- **水面舰艇航道**：切此层，把可供舰艇航行的水面画成闭合区域/宽笔刷；
  也可以先点 **水域→舰艇** 复制整片水域，再擦掉不该走的窄段。不画则舰艇直接用水域。
- 多边形：左键逐点；撤销键删上一个点；双击/Enter/“完成多边形”闭合；
  “取消多边形”放弃当前点。
- 每张图切换/关闭窗口自动保存；也可以点“保存当前地图”。
- 完成后让助手运行 `python tools/build_maps.py` 并重新打包 APK。
